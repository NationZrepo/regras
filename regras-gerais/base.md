# Base

#### Regras de Base

**1.1** - Não é permitido construir bases próximas a pontos de loot, como residências, áreas militares ou locais similares.

**1.2** - Cada clã pode possuir no máximo 1 base.

**1.3** - É proibida a construção de bases nos seguintes locais: metrô, lojas de conveniência, barbearias, lojas de roupas, estúdios de tatuagem, Ammu-Nation, túneis de esgoto, postos de combustível, áreas militares, bancos Fleeca e Vanilla.

**1.4** - As bases devem possuir uma estrutura coerente e plausível, não sendo permitido construções irreais, como estruturas flutuando no ar ou sobre a água sem suporte.

**1.5** - Não é permitido bloquear o acesso a escadas de mão.

**1.6** - Caso o jogador entre no servidor e esteja dentro de uma base, não deve interagir com o local. É necessário abrir um ticket para que a equipe administrativa realize a remoção. (Situação comum quando uma base é construída no local onde o jogador havia desconectado).

**1.7** - É proibida a construção de bases sobre estradas ou trilhos. Estruturas nessas condições poderão ser removidas sem aviso prévio.

**1.8** - O acesso à base deve ser possível sem a necessidade de ações forçadas por parte de quem estiver invadindo, como pular obstáculos específicos, nadar ou executar animações obrigatórias.

**1.9** - Não é permitido bloquear ou impedir o acesso a locais que contenham loot.

***

#### Dimensões da Base

**2.1** - As bases devem respeitar os seguintes limites de construção:

* **Máximo de 20 fundações/telhados**
* **Máximo de 4 portas**
* **Máximo de 3 portões grandes**
* **Máximo de 20 baús**
* **Altura máxima de 5 andares**

**2.2** - Esses limites têm como objetivo garantir um sistema de invasão (raid) equilibrado e justo para todos os jogadores.
