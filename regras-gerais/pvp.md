# PvP

**1.1** - O PVP fica desativado durante o dia in-game devido ao modo PVE, sendo liberado durante a madrugada, das **22:00 às 06:59** (horário do ciclo interno do jogo), além de sempre liberado durante os horários de raid e dentro de áreas de eventos. Consulte [PvE](pve.md) para mais detalhes. Qualquer forma de trapaça resultará em punição.

**1.2** - O uso de metagaming é proibido.

**1.3** - Não é permitido realizar combat logging (desconectar durante combate). Caso isso ocorra, o jogador poderá ser punido e perder todo o loot envolvido.

**1.4** - Para manter o equilíbrio do combate, é proibido o uso de VDM (utilizar veículos para causar dano ou eliminar jogadores de forma indevida).

**1.5** - Não é permitido praticar flaming (ofensas, provocações excessivas ou comportamento tóxico).

**1.6** - É proibido o uso de programas ilegais, hacks, exploração de bugs, falhas de textura, “no prop” ou qualquer outro tipo de trapaça.

**1.7** - Ao acionar um airdrop dentro da própria base, o jogador assume o risco de invasão, permitindo que outros jogadores tentem acessar o local para disputar o loot.

**1.8** - Não é permitido desconectar em áreas de loot que exigem cartão de acesso para abertura.

**1.9** - É proibido utilizar falhas de renderização para obter vantagem em combate, como atingir jogadores dentro de bases.

**1.10** - Caso um jogador utilize sua base como ponto de ataque contra outros ao redor, o local passa a ser considerado uma área ativa de PVP, permitindo que outros jogadores invadam a base para reagir, eliminar o atacante ou disputar o loot.
